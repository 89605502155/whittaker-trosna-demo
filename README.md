# whittaker-trosna-demo

Воспроизведение графиков и результатов вычислительного эксперимента статьи о сглаживании Уиттекера
с учётом давности наблюдений (А. О. Ферубко, О. Д. Казаков). Сам метод реализован в библиотеке
[whittaker-trosna](https://github.com/89605502155/whittaker-trosna) (`pip install whittaker-trosna`).

Ноутбук [`demo.ipynb`](demo.ipynb) самодостаточен: в нём заданы модельные ряды, единый интерфейс к трём
сравниваемым библиотекам (whittaker-trosna 0.2.1, whittaker-eilers 0.2.0, vam.whittaker 2.0.6) и код
каждого рисунка. Все случайные ряды порождаются с фиксированными зёрнами, поэтому числа совпадают со статьёй.
Ноутбук сохранён с результатами выполнения, их можно посмотреть прямо на GitHub.

| В статье | Что строит ноутбук |
|---|---|
| Рис. 1 | весовые функции давности наблюдений |
| Табл. 2 | ошибки сглаживания пяти модельных рядов (100 реализаций шума) |
| Рис. 5 | ряд «синусоида и парабола» и зависимость ошибки от длительности участка после изменения |
| Рис. 6 | последние 100 наблюдений четырёх модельных рядов |
| Табл. 1 | совпадение реализаций при одинаковой λ и время работы |

Рис. 2–4 статьи являются блок-схемами алгоритмов и здесь не строятся.

## Запуск

Нужны Python 3.11 (проверено) и компилятор C (vam.whittaker собирается из исходного кода).

```bash
git clone https://github.com/89605502155/whittaker-trosna-demo.git
cd whittaker-trosna-demo
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook demo.ipynb
```

Полное выполнение ноутбука занимает несколько минут, основное время уходит на табл. 2. Для быстрой
проверки уменьшите `RUNS` и `TL_RUNS` в соответствующих ячейках.

Выполнить ноутбук без браузера:

```bash
jupyter nbconvert --to notebook --execute --inplace demo.ipynb
```
